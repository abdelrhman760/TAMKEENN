TAMKEEN v3 – مشروع جامعي تجريبي لمنصة ويب دامجة
================================================

محتويات المشروع
- index.html: الصفحة الرئيسية والتعريف بالخدمات.
- learning.html: مكتبة تعليمية مصنفة حسب احتياج الدعم، مع دروس وأنشطة قصيرة.
- tools.html: أدوات المساعدة البصرية والسمعية، OCR، تنظيم التعلم والمهام.
- communication.html: لوحة تواصل بالصور والعبارات (AAC).
- account.html: ملف شخصي تجريبي وإعدادات دعم.
- learning.js: إدارة الدروس والاختبارات وحفظ التقدم محليًا.
- accessibility.js: إعدادات الإتاحة العامة.

تشغيل محلي
1) فك ضغط الملف.
2) افتح مجلد TAMKEEN في Visual Studio Code.
3) شغّل index.html باستخدام Live Server.
4) استخدم Chrome أو Edge للحصول على أفضل دعم تجريبي لخصائص الصوت.

نشر الموقع على الإنترنت (مناسب للعرض الجامعي)
الخيار المقترح: GitHub Pages أو Netlify.
- أنشئ مستودع GitHub وارفع جميع ملفات ومجلدات TAMKEEN كما هي.
- في GitHub: Settings > Pages > Deploy from a branch، ثم اختر main والمجلد /root.
- أو اسحب مجلد المشروع إلى Netlify Drop لإنشاء رابط معاينة.
- بعد النشر اختبر الموقع على الهاتف والكمبيوتر، وتأكد من فتحه عبر HTTPS للسماح بالكاميرا والميكروفون.

الخصائص التجريبية
- استخراج النص من الصور عبر Tesseract.js من CDN، ويتطلب الإنترنت لتحميل المحرك وبيانات اللغة.
- الكاميرا والميكروفون يحتاجان HTTPS أو localhost وإذن المستخدم.
- القراءة الصوتية تستخدم SpeechSynthesis وأصوات الجهاز.
- التعرف على الكلام يعتمد على Web Speech API ودعم المتصفح واللغة.
- تقدم المكتبة والمهام والإعدادات التجريبية تحفظ في localStorage على نفس الجهاز والمتصفح.
- الحساب الحالي ليس مصادقة آمنة ولا يجب استخدام كلمات مرور حقيقية أو بيانات حساسة.

حدود مهمة قبل الاستخدام الحقيقي
هذا نموذج Front-End تعليمي للعرض الجامعي وليس خدمة طبية أو تشخيصية أو نظامًا إنتاجيًا.
لا توجد قاعدة بيانات أو مزامنة بين الأجهزة أو إدارة مستخدمين آمنة.
يجب إضافة Backend آمن، تشفير كلمات المرور، صلاحيات، نسخ احتياطي وسياسة خصوصية قبل الإطلاق العام.
المحتوى التعليمي والأنشطة أمثلة أولية ويجب مراجعتها مع متخصصين وتجربتها مع مستخدمين ذوي إعاقات متنوعة.
يجب توفير بدائل نصية، تباين مناسب، تنقل بلوحة المفاتيح، وعدم الاعتماد على اللون أو الصوت وحدهما.

أفكار لتطوير المرحلة التالية
- لوحة تحكم للمشرف لإضافة الدروس والأنشطة.
- قاعدة بيانات وحسابات آمنة وتقدم متزامن.
- إدارة محتوى متعدد الوسائط مع نص بديل وترجمة/تعليقات توضيحية.
- اختبار قابلية الاستخدام وفق WCAG 2.2 AA ومراجعة بشرية.
- دمج مساعد ذكاء اصطناعي عبر خادم وسيط مع حماية مفاتيح API ومراجعة دقة المخرجات.
